Tester getting-started checklist
  1. Add the tester’s verified sign-in email with Beta access set to Allowed. Choose complimentary Pro independently.
  2. Ask the tester to open https://paddlelog.leewaypb.com and sign in using the verified email saved above.
  3. Add their actual paddle. Start a session when playing, pause for breaks, then finish and review before saving. A past session or Pickle Point import works too.
  4. Check the hours and maintenance status, then try Paddles and History.
  5. Report friction in Settings → Feedback & support. Include what happened, the expected result, and steps to repeat. Feedback opens a draft for the tester to send.

Free includes five paddles total. Pro tester access can be turned off to test the upgrade prompts; saved records stay available.

How beta access works

Saving authorizes beta access and sets complimentary Pro independently. Share the PaddleLog link yourself; saving does not send an email. No ChatGPT account is required.

The invitation binds to the first account that signs in with this verified email. Apple Hide My Email may use a different address. Once linked, access stays bound to that account.

Blocking beta access stops private library access without deleting data. Turning complimentary Pro off keeps beta access and saved records. The free plan allows five paddles total, including archived paddles.
