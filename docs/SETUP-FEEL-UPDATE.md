# Setup and feel update

Account controls live in Settings > Account. Setup has independent top, sides and butt-cap notes plus undergrip selection/details. These persistent accessories also produce configuration modification inputs for Competition Check; they never create maintenance events. Feel is a user assessment on a 0–100 soft/stiff and hollow/dense grid, not reviewer or verified data.

Legacy sweetSpot, feelProfile, startDate, endDate and replacesPaddleId remain in backups but are no longer editable/displayed. Existing weightSetup is retained as additional setup notes. Added date uses createdAt. Newly archived records get archivedAt, disposition and append-only archiveHistory; legacy archived dates remain unknown. Reactivation clears the current archivedAt but retains history. No sessions or maintenance records migrate.

Automated coverage: full test suite, actual HTML DOM simulation of Account controls, setup edits, feel sliders/draft recovery, archive Sold, repeated save preserving archive time, details, and missing retired form fields. Browser/iPhone visual testing is unavailable in this session.
