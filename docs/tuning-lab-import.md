# Tuning Lab integration removed

The PE-specific image upload, OCR scan/review, promotion link, and imported setup/diagram display have been removed. OCR browser assets are no longer shipped.

No data migration or value rollback is performed. User-entered measurements, structured weights, undergrips, and notes remain editable. Previously confirmed values remain stored, with original estimate provenance where applicable. Legacy image references and import metadata remain in backups and schema validation to avoid destructive data loss. They are not displayed as a setup or used to overwrite measurements.
