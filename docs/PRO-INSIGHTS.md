# Pro insights

Open Insights · Pro above the paddle collection. Select all paddles or a single active/inactive/archived paddle and choose the last 12 calendar weeks or months. Entitlement refresh uses the existing account-bound internal Pro service; no Apple-specific decisions. Non-Pro users see the contextual upgrade dialog. Failed verification does not open analytics, and entitlement refresh with no active Pro closes an open dashboard.

`public/analytics.js` holds pure projections and `public/analytics-ui.js` renders the mobile dialog. No record writes, new tables, fabricated observations, or schema migrations. All usage comes from the existing `sessionUsage`/`estimateContribution` implementation. Session boundaries are clipped to local calendar buckets and estimate residuals are distributed only across unlogged time. Monday starts each week. The current period includes saved usage until its end; total lifetime usage includes all saved sessions, consistent with wear. Overlapping logged sessions retain existing app semantics and count as recorded. Estimated usage is shown separately and never counted as a logged session.

Lifecycle: days tracked is added-to-archive (for currently archived paddles) or added-to-now. It is calendar tracking duration, not known active rotation time. Historical reactivations and inactive periods cannot be reconstructed from incomplete status history. Logged-session count and starts within trailing 30 days describe frequency without inferring unlogged session counts.

Performance: dated stored measurement snapshots, ordered by timestamp, with missing/invalid values excluded and consecutive identical values suppressed. Does not include predicted setup calculations or manufacturer references. No claim of causality, standardized testing, or verified specs. Existing historical timestamps are preserved. Future new snapshots use the draft's stable save-at time instead of when editing began. Tables expose exact saved values; graphs scale y to observed values and x to timestamps. Single-point and absent history have explicit states.

Maintenance: each known installation ends at the next same-kind install/removal, independent of other consumables. The range uses authoritative sessions and residual estimates. Open cycles are shown but excluded from completed-cycle averages. Unknown pre-installation use cannot be assigned. Averages describe replacement behavior, not manufacturer lifespan or recommended wear intervals.

Tests: usage residuals, corrections/deletion, cross-month splits, calendar week/month continuity, DST, archive duration/missing dates, independent consumable cycles, dated metric ordering/missing values, UI empty states, live data refresh, entitlement denial/expiry, plus existing regression suite. Native/web build and TypeScript checks. Physical iPhone visual/gesture validation remains outstanding.
