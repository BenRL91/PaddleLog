# Session ball selection

Ball selection remains the existing optional session `ball` string. No migration or rewritten historical records. Empty = not recorded; `Unknown` explicitly records that the player does not know. Selecting Other allows any name. Previous session/location ball names remain available; draft recovery and editing preserve custom values.

Starter options and official name sources, checked 2026-10-02:
- Franklin X-40 / X-26: https://franklinsports.com/sports/pickleball/balls
- ONIX Dura Fast 40 / Fuse G2: https://www.onixpickleball.com/collections/tournament-balls
- Selkirk Pro S1: https://www.selkirk.com/products/pro-s1-pickleballs

Additional requested options (2026-10-02): Life Time LT Pro 48 (https://shop.lifetime.life/lt-pro-48-pickleball); Franklin X-44 (user-requested name; manufacturer listing not found during this check).

These are names for logging, not approval, performance, or tournament eligibility claims. The starter list in app.js can be expanded independently of stored session records. No automatic change to indoor/outdoor when a ball is selected.

Saved-location suggestions use only the current account's location defaults. Selecting/type-matching a saved name selects the defaults dropdown but does not apply ball, net, or setting without the existing confirmation. Weather is never reused. External address autocomplete remains a separate future integration requiring a provider.
